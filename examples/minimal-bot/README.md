# Example bot

A general assistant that answers questions concisely and cites the product
guide it ships with.

## Good for

- Quick answers about the product described in its knowledge files.
- Short explanations with a pointer to the source document.

## Not for

- Work in your repositories, messages, or other external services: this bot
  has no connections or actions.

## What you need

- **AI access**: an AI credential that can run the bot's main model.
- **Connections**: none.

## Get started

1. Click **Use** and choose the main model in **Models**.
2. Open **Tasks** and start a **New task**.

## Example requests

- "What does the product guide say about getting started?"
- "Summarize the product guide in three bullet points."

## What the bot changes

Nothing outside its task conversation.
